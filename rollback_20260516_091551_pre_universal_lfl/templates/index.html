🎯 Scenarios — set venue growth targets & comments

            

                Create up to 3 scenarios (e.g. Base / Stretch / Conservative). For each venue, enter the full-year FY27 growth % you want — the model calibrates a single daily multiplier per venue so the FY27 total exactly equals FY26 baseline × (1 + growth%). Add up to 5 free-text comments per venue. Switch the active scenario at any time — every chart and table updates instantly.

The calibration multiplies Prophet's daily forecast by a single scalar — preserving Prophet's weekly/seasonal phasing — to hit the target. Use this to pull back excessive ramp-ups or lock in budget targets.
